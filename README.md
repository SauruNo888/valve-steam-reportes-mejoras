# Sistema de Gestión de Reportes y Mejoras de Steam

## Descripción del proyecto

Este proyecto propone un sistema para organizar la recepción, el seguimiento y la resolución de reportes de problemas relacionados con Steam, la plataforma de distribución digital de videojuegos de Valve Software.

La propuesta busca mejorar la organización de los reportes, facilitar su seguimiento y mantener un registro de las soluciones aplicadas.

Este trabajo tiene fines académicos y no representa un sistema oficial de Valve.

## Objetivo

Diseñar una propuesta de gestión de reportes que permita organizar las tareas de soporte y desarrollo, documentar los procesos y establecer mecanismos de control para evaluar el funcionamiento del sistema.

## Alcance

El proyecto contempla:

- Registro de reportes de problemas.
- Clasificación y asignación de prioridades.
- Consulta del estado de cada reporte.
- Registro de las soluciones propuestas.
- Revisión y documentación de las correcciones.
- Seguimiento de indicadores de desempeño.

## Historias de usuario

- HU-01: Registrar un reporte.
- HU-02: Consultar el estado de un reporte.
- HU-03: Revisar y cerrar una solución.
