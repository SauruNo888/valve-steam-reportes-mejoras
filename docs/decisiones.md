# Registro de decisiones del proyecto

## Decisión 1: Alcance del proyecto

Se decidió utilizar como caso de estudio la plataforma Steam, desarrollada por Valve Software, para elaborar una propuesta académica de gestión de reportes y mejoras.

## Decisión 2: Proceso seleccionado

Se seleccionó el proceso de recepción, análisis, seguimiento y resolución de reportes porque permite identificar actividades, responsables, decisiones y mecanismos de control.

## Decisión 3: Herramientas de colaboración

Se propone utilizar Git y GitHub para documentar los cambios, trabajar con ramas y revisar las modificaciones mediante Pull Requests.

## Decisión 4: Gestión de tareas

Se propone utilizar GitHub Projects para organizar las historias de usuario y realizar el seguimiento de las tareas.

## Decisión 5: Control del proceso

Se definieron indicadores relacionados con el tiempo de respuesta, la calidad de los datos, la resolución de reportes, las reaperturas y la revisión de cambios.
