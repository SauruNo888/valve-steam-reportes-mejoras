# Historias de usuario

## HU-01: Registrar un reporte

**Historia de usuario**

Como usuario de Steam, quiero registrar un problema indicando su descripción y evidencia, para que el equipo pueda analizarlo.

**Criterios de aceptación**

- El formulario solicita los datos mínimos necesarios.
- El sistema confirma que el reporte fue registrado.
- Cada reporte recibe un identificador único.

**Prioridad:** Alta.

## HU-02: Consultar el estado de un reporte

**Historia de usuario**

Como usuario que envió un reporte, quiero consultar su estado, para saber si está recibido, en análisis, pendiente o resuelto.

**Criterios de aceptación**

- Cada reporte tiene un estado identificable.
- Los cambios de estado quedan registrados.
- La consulta muestra la información correspondiente al reporte seleccionado.

**Prioridad:** Media.

## HU-03: Revisar y cerrar una solución

**Historia de usuario**

Como integrante del equipo técnico, quiero registrar la solución y sus pruebas, para cerrar el reporte con evidencia y trazabilidad.

**Criterios de aceptación**

- La solución incluye una descripción del trabajo realizado.
- Se registra el resultado de las pruebas.
- El cierre del reporte genera una notificación al usuario.

**Prioridad:** Media.
